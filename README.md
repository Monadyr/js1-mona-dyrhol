# Square Eyes

A movie purchasing website built as part of my Front-end Development assignment for JavaScript. 

## Description

This project is a movie shopping website where users can browse movies, view individual movie details, filter movies by genre, add movies to shopping cart, and complete a simulated checkout.

Data is fetch dynamically from Noroff Square Eyes API

## Features

- Browse movies on the homepage 
- View individual movie details 
- Filter movies by genre 
- Add movies to the shopping cart 
- Increase movie quantity 
- Remove movies from the cart 
- View cart contents 
- Calculate subtotal, shipping and total price

## Technologies used

The project is build with
- HTML
- CSS
- Vanilla JavaScript
- Noroff Square Eyes API
- LocalStorage
- SessionStorage

## Running the project

Clone or download the repository and open the project using a local development server.
